# Trend Pullback historical research corpus

`atb-research-corpus` is a research-only, read-only adapter over the shared fail-closed historical
source selector. Generic sources use the configured or explicit generic Parquet root. Qualified
`weex-v3-last-*` sources require `--dataset-version` and resolve only through the immutable
`LockedWeexResearchCorpusStore` below `ATB_QUALIFIED_RESEARCH_CORPUS_ROOT`. It emits the complete
Trend Pullback 15-minute decision population generated by the existing Replay, Feature,
Structure, Regime, Strategy, Risk, Safety, and Decision Journal authorities.

The configured `start` and `end` bound candle open times as `[start, end)`, matching
`ReplaySeries`. Because a candle becomes observable only when it closes, emitted decision times
occupy `(start, end]`. The range must align to 15m, 1h, and 4h boundaries.

Qualified WEEX example:

```console
atb-research-corpus \
  --source weex-v3-last-e5b0c4035a19d5a80ca7 \
  --dataset-version weex-v1-5m-last-a629a29b580b2e103adba918 \
  --symbol BTC/USDT \
  --start 2025-04-10T08:00:00Z \
  --end 2026-01-01T00:00:00Z \
  --research-equity 10000 \
  --speed 100x \
  --output trend-pullback-corpus.json
```

`--data-root` is intentionally never an override for the qualified WEEX namespace. Missing or
unknown versions, mixed generic/qualified sources, source/version mismatches, changed bytes, or
unqualified ranges fail closed without a fresh API fallback.

Generic-source example:

```console
atb-research-corpus \
  --data-root data/historical \
  --source binance-public \
  --symbol BTC/USDT \
  --symbol ETH/USDT \
  --start 2025-01-01T00:00:00Z \
  --end 2026-01-01T00:00:00Z \
  --research-equity 10000 \
  --speed 100x \
  --output trend-pullback-corpus.json
```

The fixed research equity is independently reset for every candidate. Day-start and peak equity
equal that equity, with no carried positions, open risk, or gross exposure. This is deliberately
not a portfolio simulation.

The default Safety profile explicitly assumes a healthy exchange API, zero spread, zero clock
offset, normal classified volatility, no suspicious anomaly, and no prior order rejections only
to exercise the existing Safety contract. `historical_operational_facts_observed` is permanently
false: these values are declared research assumptions, not claims about historical exchange or
operational conditions. “Research admissible” therefore means cleared under this configuration,
not that a candidate would necessarily have been approved live.

The JSON artifact is deterministic, versioned, lossless for Decimal values, tamper-evident, and
marked `research_only` / `is_trading_authority: false`. It contains no exits, outcomes, PnL,
portfolio simulation, optimization, Experience input, or runtime trading behavior.
